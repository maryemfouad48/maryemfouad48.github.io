# Maryem Fouad — Portfolio

A dark developer portfolio built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace the three practice project cards with the real project links when the projects are completed.
2. Add GitHub when you have a public GitHub profile.
3. Review all wording and contact details.

## Publish with GitHub Pages
Create a GitHub repository, upload all files while keeping the same folder structure, then enable GitHub Pages from the repository settings.
